# Help-Meh 📝

A simple, collaborative to-do list tracker designed for teams and groups to manage shared tasks in real time.

🔗 **Live Demo:** [https://help-meh.vercel.app/](https://help-meh.vercel.app/)

---

## ✨ Features

- **Group Task Tracking:** Create and manage shared to-do lists across team members or groups.
- **Real-Time Progress:** Keep everyone aligned on task statuses and completion.
- **Clean & Simple UI:** Straightforward design focused on getting things done without clutter.

---

## 🛠️ Built With

- **Framework:** Next.js
- **Deployment:** Vercel
